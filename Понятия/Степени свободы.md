# Степени свободы

%% lecnotes:start — блок ниже обновляется автоматически, правки в нём перезапишутся %%
> [!info] Определение
> Число независимых отклонений из n возможных, требуемое для образования данных сумм квадратов; связано с числом единиц совокупности.
> *— из [[2025-10-25 Лекция 4. Оценка параметров линейной регрессии#Оценка параметров линейной регрессии|лекции]]*

## Упоминания в лекциях
- [[2025-10-25 Лекция 4. Оценка параметров линейной регрессии#Оценка параметров линейной регрессии|25.10 · Количественный анализ → Оценка параметров линейной регрессии]] — Число степеней свободы связано с количеством независимых отклонений из n возможных, необходимых для образования сумм квадратов.
- [[2025-11-21 Лекция 6. Спецификация и мультиколлинеарность в регрессии#Статистический тест на мультиколлинеарность|21.11 · Количественный анализ → Статистический тест на мультиколлинеарность]] — Статистика теста имеет приближенное распределение хи-квадрат с количеством степеней свободы, равным 0.5 * n * (n-1), где n — количество факторов.

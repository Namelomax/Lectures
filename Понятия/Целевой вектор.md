# Целевой вектор

%% lecnotes:start — блок ниже обновляется автоматически, правки в нём перезапишутся %%
> [!info] Определение
> Вектор коэффициентов целевой функции, определяющий направление перемещения линий уровня для максимизации или минимизации.
> *— из [[2025-09-22 Лекция 3. Графический метод решения задачи#Определение оптимального плана графически|лекции]]*

## Упоминания в лекциях
- [[2025-09-04 Лекция 1. Линейное программирование и оптимизация инвестиций#Формализация задачи линейного программирования|04.09 · Исследование операций → Формализация задачи линейного программирования]] — Целевой вектор состоит из коэффициентов при переменных в целевой функции.
- [[2025-09-22 Лекция 3. Графический метод решения задачи#Определение оптимального плана графически|22.09 · Исследование операций → Определение оптимального плана графически]] — Целевой вектор указывает направление перемещения линий уровня для поиска оптимума.
- [[2025-10-01 Лекция 4. Оптимизация закупки витаминных комплексов#Анализ чувствительности целевого вектора|01.10 · Исследование операций → Анализ чувствительности целевого вектора]] — Граничное положение целевого вектора соответствует случаю, когда линия уровня совпадает с ограничением $P_1$ ($3x_1+x_2=9$).

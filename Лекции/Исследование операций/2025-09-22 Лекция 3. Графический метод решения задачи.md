# Лекция 3. Графический метод решения задачи

> [!abstract] Кратко
> Лекция посвящена графическому методу решения задач линейного программирования. Рассматривается геометрический смысл целевой функции и линий уровня. Описан алгоритм поиска оптимального плана через перемещение линий уровня. Приведён конкретный пример с расчётом координат оптимума и значения целевой функции.

> [!tip] Главное
> - Оптимальный план находится в крайней точке допустимого множества, наиболее удалённой в направлении целевого вектора.
> - Линии уровня представляют собой прямые, параллельные друг другу, которые перемещаются для поиска оптимума.
> - Координаты оптимального решения определяются точкой пересечения последней линии уровня с границей допустимой области.
> - Значение целевой функции в оптимуме вычисляется подстановкой координат оптимальной точки в уравнение целевой функции.

## Определение оптимального плана графически

- Целевой вектор указывает направление перемещения линий уровня для поиска оптимума.
- Оптимальный план определяется как точка пересечения линии уровня с допустимым множеством, наиболее удаленная в направлении целевого вектора.
- Линии уровня задаются уравнением $c_1 x_1 + c_2 x_2 = a$, где $a$ — параметр, меняющийся при перемещении линии.
- Для вектора $c=(3,2)$ рассмотрены линии уровня с $a=6$ и $a=12$.
- Линия уровня $3x_1+2x_2=6$ проходит через точки $(0,3)$ и $(2,0)$.
- Линия уровня $3x_1+2x_2=12$ проходит через точки $(0,6)$ и $(4,0)$.
- Алгоритм поиска оптимума включает определение произвольных линий уровня и их перемещение до крайней точки допустимого множества.
- Координаты оптимального плана в данном примере составляют $(10/3, 4/3)$.
- Значение целевой функции в оптимальной точке равно $f(x) = 3(10/3) + 2(4/3) = 38/3 = 12 \frac{2}{3}$.

> [!info] Определение: Целевой вектор
> Вектор коэффициентов целевой функции, определяющий направление перемещения линий уровня для максимизации или минимизации.

> [!info] Определение: Линия уровня
> Геометрическое отображение целевой функции при фиксированном значении $a$, используемое для графического поиска оптимума.

> [!example] Примеры
> - Расчет значения целевой функции для точки $(10/3, 4/3)$ с вектором $(3,2)$, результат $12 \frac{2}{3}$.

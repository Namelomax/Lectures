# Транспортная задача и динамическое программирование

> [!abstract] Кратко
> Лекция рассматривает методы решения транспортных задач, включая алгоритм потенциалов для минимизации логистических издержек. Особое внимание уделяется задаче о назначениях как частному случаю транспортной модели. Вторая часть посвящена динамическому программированию и принципу оптимальности Белмана. На примере распределения инвестиций показано итеративное построение оптимального плана через последовательное добавление этапов.

> [!tip] Главное
> - Метод потенциалов позволяет проверять оптимальность плана перевозок и корректировать его через циклы перераспределения.
> - Задача о назначениях является частным случаем транспортной задачи с квадратной матрицей затрат.
> - Принцип оптимальности Белмана лежит в основе динамического программирования, разбивая сложную задачу на последовательные подзадачи.
> - Итеративный подход в динамическом программировании позволяет находить глобальный оптимум путем локальных оптимизаций на каждом шаге.

## Транспортная задача и метод потенциалов

- Транспортная задача направлена на определение объемов перевозок от нескольких поставщиков к нескольким потребителям с минимальной суммарной стоимостью.
- Математическая модель включает ограничения по запасам поставщиков и потребностям потребителей, при этом задача имеет решение только в сбалансированном случае.
- Для решения используется метод потенциалов, где вычисляются значения U и V для базисных переменных.
- Оптимальность плана проверяется по условию U_i + V_j <= c_ij для всех небазисных клеток.
- Если условие нарушается, строится цикл перераспределения, и объемы перевозок корректируются в сторону клетки с максимальным потенциалом.
- Итеративный процесс продолжается до тех пор, пока не будет получен оптимальный план, минимизирующий целевую функцию.
- В примере с тремя поставщиками и четырьмя потребителями начальный план имел стоимость 1350, а после одной итерации улучшился до 1330.

> [!info] Определение: Транспортная задача
> Задача линейного программирования, направленная на минимизацию суммарных затрат на перевозку грузов от поставщиков к потребителям при заданных запасах и потребностях.

> [!info] Определение: Метод потенциалов
> Алгоритм решения транспортной задачи, основанный на вычислении потенциалов U и V для проверки оптимальности текущего плана и построения цикла перераспределения.

> [!example] Примеры
> - Решение задачи с матрицей тарифов 3x4, где запасы составили 160, 140, 170, а потребности 120, 50, 190, 110.
> - Демонстрация перехода от плана X1 (стоимость 1350) к плану X2 (стоимость 1330) через цикл 5-8-2-1-3-2-5.

## Задача о назначениях и динамическое программирование

- Задача о назначениях является частным случаем транспортной задачи, где нужно распределить исполнителей по работам с минимальными затратами.
- В задаче о распределении инвестиций рассматривается распределение средств между предприятиями для максимизации общей прибыли.
- Принцип оптимальности Белмана применяется для решения задач динамического программирования, разбивая процесс на шаги.
- При расчете учитывается, что прибыль от каждого предприятия выражается в одних условных единицах и не зависит от вложений в другие объекты.
- Решение строится итеративно: на каждом шаге вычисляется оптимальная стоимость для каждого возможного объема средств.
- На первом шаге рассматривается распределение средств между первыми двумя предприятиями, на втором — добавляется третье, и так далее.
- Итоговый оптимальный план определяется по максимальному значению целевой функции на последнем шаге.

> [!info] Определение: Задача о назначениях
> Специальный случай транспортной задачи, в котором нужно назначить исполнителей на работы так, чтобы минимизировать суммарные затраты.

> [!info] Определение: Принцип оптимальности Белмана
> Фундаментальный принцип динамического программирования, согласно которому оптимальная стратегия должна быть оптимальной для всех оставшихся подзадач.

> [!example] Примеры
> - Распределение 5 условных единиц между 4 промышленными предприятиями с использованием таблицы прибылей.
> - Пошаговый расчет оптимальных значений для каждого уровня вложений от 0 до 5 единиц.

# Экономическая модель задачи линейного программирования

> [!abstract] Кратко
> Лекция посвящена экономическому смыслу задачи линейного программирования, рассматриваемой как оптимизация выпуска продукции. Описаны ключевые параметры модели: коэффициенты расхода ресурсов, удельные доходы и запасы сырья. Показано, как эти данные систематизируются в таблицу для анализа. Сформулирована математическая модель, включающая целевую функцию максимизации дохода и ограничения по дефицитным ресурсам.

> [!tip] Главное
> - Задача линейного программирования интерпретируется как поиск оптимального плана выпуска продукции для максимизации дохода.
> - Входные данные задачи включают коэффициенты расхода ресурсов, удельные доходы и доступные запасы сырья.
> - Математическая модель состоит из линейной целевой функции и системы линейных неравенств.
> - Ограничения отражают физическую невозможность использовать ресурсы сверх их имеющихся запасов.
> - Переменные модели представляют собой объемы выпуска каждого вида продукции.

## Экономическая интерпретация задачи

- Задача линейного программирования формулируется как организация выпуска n видов продукции P1...Pn из имеющихся ресурсов.
- Известны коэффициенты ai,j, показывающие расход ресурса Ri на единицу продукции Pj.
- Известны удельные доходы cj от реализации единицы продукции Pj.
- Известны запасы ресурсов bi для каждого вида ресурса Ri.
- Целью является составление плана выпуска продукции, максимизирующего ожидаемый суммарный доход.
- Данные задачи систематизируются в таблицу, где строки соответствуют ресурсам, а столбцы — видам продукции.
- В таблице также указываются запасы ресурсов и удельные доходы по каждому виду продукции.

> [!info] Определение: Удельный доход
> Доход от реализации единицы продукции Pj, обозначаемый как cj.

## Математическая модель задачи

- Целевая функция задачи записывается как f(x) = c1*x1 + ... + cn*xn, стремящаяся к максимуму.
- Переменные xj представляют объемы выпуска продукции j-го вида.
- Ограничения по ресурсам записываются в виде системы неравенств.
- Для каждого ресурса Ri сумма затрат ресурсов на производство всех видов продукции не должна превышать его запас bi.
- Общая математическая модель включает целевую функцию и систему ограничений по ресурсам.
- Ссылки на предыдущую и следующую лекции указывают на место данного материала в курсе.

> [!info] Определение: Ограничения задачи
> Система неравенств, отражающая дефицитность ресурсов: сумма расхода ресурсов на производство продукции не превышает их доступные запасы.

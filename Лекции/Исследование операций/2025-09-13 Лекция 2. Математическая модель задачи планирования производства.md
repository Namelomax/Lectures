# Лекция 2. Математическая модель задачи планирования производства

> [!abstract] Кратко
> Лекция посвящена формализации задачи организации выпуска продукции. Рассматривается экономическая интерпретация задачи с учетом затрат ресурсов и удельных доходов. Вводится математическая модель, включающая целевую функцию максимизации прибыли и систему ограничений по доступным ресурсам. Описана структура данных в виде таблицы и связь переменных с физическим смыслом.

> [!tip] Главное
> - Задача сводится к максимизации суммарного дохода при ограниченных запасах ресурсов.
> - Экономические параметры (затраты, доходы, запасы) структурируются в матрицу данных.
> - Математическая модель состоит из линейной целевой функции и системы линейных неравенств.
> - Переменные xj представляют объемы выпуска, а ограничения связывают их с доступными ресурсами.

## Экономическая интерпретация и данные задачи

- Рассматривается задача организации выпуска n видов продукции P1, P2, ..., Pn.
- Известны затраты ресурсов ai на единицу продукции Pj, удельный доход cj от реализации единицы продукции Pj и запасы ресурсов bi.
- Целью является составление плана выпуска продукции, при котором ожидаемый суммарный доход будет максимальным.
- Данные задачи удобно представлять в виде таблицы, где строки соответствуют ресурсам, а столбцы — видам продукции.
- В таблице фиксируются коэффициенты расхода ресурсов ai, запасы ресурсов bi и удельные доходы cj.
- Переменные xj обозначают объемы выпуска каждого вида продукции.

> [!info] Определение: Удельный доход
> Доход от реализации единицы продукции Pj, обозначаемый как cj.

> [!info] Определение: Запас ресурса
> Доступное количество ресурса Ri, обозначаемое как bi.

## Математическая модель и ограничения

- Целевая функция задачи имеет вид f(x) = c1*x1 + ... + cn*xn и стремится к максимуму.
- Ограничения по ресурсам записываются в виде системы неравенств: сумма произведений затрат ресурсов на объемы выпуска не превышает запас ресурса.
- Для каждого ресурса Ri (i = 1, ..., m) записывается неравенство: a_i1*x1 + ... + a_in*xn <= bi.
- Математическая модель включает целевую функцию и систему ограничений, описывающих использование ресурсов.

> [!info] Определение: Математическая модель
> Формализованное описание задачи, включающее целевую функцию и ограничения, связывающие переменные с доступными ресурсами.

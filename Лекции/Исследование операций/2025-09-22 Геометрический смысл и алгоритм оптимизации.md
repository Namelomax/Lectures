# Геометрический смысл и алгоритм оптимизации

> [!abstract] Кратко
> Лекция раскрывает геометрическую интерпретацию линейного программирования через целевой вектор и линии уровня. Описан алгоритм нахождения оптимального плана путем перемещения линии уровня в направлении целевого вектора. Приведен пример вычисления координат оптимального решения и значения целевой функции. Показана связь между уравнением линии уровня и координатами точек пересечения с осями.

> [!tip] Главное
> - Целевой вектор определяет направление смещения линий уровня для поиска экстремума.
> - Оптимальный план находится в крайней точке пересечения линии уровня с допустимым множеством.
> - Уравнение линии уровня $c_1x_1+c_2x_2=a$ позволяет определить координаты точек на осях.
> - Значение целевой функции в оптимальной точке вычисляется подстановкой координат в целевую функцию.
> - Алгоритм решения включает вычисление функции, построение линии уровня и ее перемещение до границы допустимой области.

## Геометрический смысл целевого вектора

- Целевой вектор указывает направление перемещения линий уровня для поиска оптимального решения.
- Оптимальный план определяется по прямым, на которых он расположен.
- Уравнение линии уровня имеет вид $c_1*x_1+c_2*x_2=a$.
- Для значения $a=6$ уравнение $3x_1+2x_2=6$ проходит через точки (0,3) и (2,0).
- Для значения $a=12$ уравнение $3x_1+2x_2=12$ проходит через точки (0,6) и (4,0).
- Целевой вектор задан координатами $c=(c_1,c_2)=(3,2)$.

> [!info] Определение: Целевой вектор
> Вектор, указывающий направление перемещения линий уровня целевой функции для достижения оптимума.

> [!example] Примеры
> - Прямая $3x_1+2x_2=6$ с точками пересечения осей (0,3) и (2,0).
> - Прямая $3x_1+2x_2=12$ с точками пересечения осей (0,6) и (4,0).

## Алгоритм нахождения оптимального плана

- Первый шаг алгоритма — вычисление значения целевой функции.
- Второй шаг — определение произвольных линий уровня задачи.
- Третий шаг — перемещение линии уровня в направлении целевого вектора.
- Перемещение продолжается до крайней точки пересечения с допустимым множеством.
- Координаты этой крайней точки определяют оптимальный план задачи.
- Значение целевой функции в найденной точке составляет $f(x)=3\frac{10}{3}+2\frac{4}{3}=\frac{38}{3}=12\frac{2}{3}$.

> [!info] Определение: Оптимальный план
> Точка допустимого множества, в которой целевая функция достигает своего экстремального значения, найденная перемещением линии уровня.

> [!example] Примеры
> - Вычисление значения функции $f(x)=\frac{38}{3}$ для найденного оптимального плана.

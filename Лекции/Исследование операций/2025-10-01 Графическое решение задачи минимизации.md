# Графическое решение задачи минимизации

> [!abstract] Кратко
> Лекция рассматривает задачу минимизации стоимости закупки витаминных комплексов с использованием метода графического решения. Описана постановка задачи с целевой функцией и системой ограничений. Проанализированы условия возникновения неоднозначности оптимального плана. Определены граничные значения коэффициентов, при которых один из ресурсов становится избыточным.

> [!tip] Главное
> - Задача минимизации стоимости решается графическим методом путем построения линий уровня целевой функции.
> - Оптимальное решение находится в вершине области допустимых решений, если целевая функция не параллельна грани.
> - Неоднозначность оптимального плана возникает, когда линия уровня совпадает с отрезком границы области.
> - Граничное условие для исключения одного из ресурсов определяется соотношением коэффициентов целевой функции.
> - При выполнении условия C1/C2 > 3 оптимальный план сводится к закупке только второго комплекса.

## Формулировка задачи минимизации

- Санаторий закупает два вида витаминных комплексов: «Здоровье» и «Долголетие».
- Целью является минимизация общей стоимости закупки при соблюдении норм потребления трех витаминов.
- Стоимость 1 г комплекса «Здоровье» составляет 500 единиц, а «Долголетие» — 400 единиц.
- Целевая функция задачи записывается как $f(x)=5x_1+4x_2\to min$.
- Ограничения задачи включают неравенства: $3x_1+x_2\geq9$, $x_1+2x_2\geq8$ и $x_1+6x_2\geq12$.
- Графическое решение задачи предполагает построение линий уровня целевой функции и ограничений.

## Условия неоднозначности оптимума

- Анализируется условие, при котором закупка комплекса «Здоровье» становится невыгодной.
- Граничное положение целевого вектора определяется совпадением линии уровня с отрезком $P_1$.
- В граничном случае оптимальный план принимает значение $x^* = (0;9)$.
- Для того чтобы комплекс «Здоровье» не закупался, отношение стоимости $C_1/C_2$ должно быть больше 3.
- Неоднозначность оптимального плана возникает, когда крайнее положение линии уровня совпадает с одним из отрезков области допустимых решений.
- Условие неоднозначности оптимального плана выражается равенством $C_1/C_2 = 3$.

# Основы и методы кластерного анализа

> [!abstract] Кратко
> Лекция посвящена сущности кластерного анализа как инструмента для группировки данных в гомогенные группы. Рассматриваются два основных подхода: иерархический анализ для малых выборок и метод k средних для больших данных. Подробно описан механизм иерархической кластеризации, основанный на последовательном слиянии кластеров. Также перечислены ключевые этапы применения метода, включая выбор метрики расстояния и интерпретацию результатов.

> [!tip] Главное
> - Кластерный анализ направлен на выявление структуры данных путем объединения схожих объектов в группы.
> - Иерархический метод эффективен для малых выборок, тогда как метод k средних оптимален для работы с большими данными.
> - В иерархическом анализе процесс начинается с отдельных наблюдений и заканчивается последовательным слиянием кластеров.
> - Расстояние между кластерами часто вычисляется как среднее значение расстояний между всеми парами точек.
> - Применение метода требует последовательного прохождения этапов от формулировки задачи до оценки достоверности результатов.

## Сущность и классификация методов

- Кластерный анализ предназначен для разбиения исходных данных на поддающиеся интерпретации группы.
- Цель метода — сгруппировать объекты так, чтобы элементы внутри одной группы были максимально схожими, а между разными группами — максимально отличными.
- В кластерном анализе группируются объекты, а целью является анализ структуры множества объектов.
- Каждый объект рассматривается как точка в пространстве признаков, а задача метода — выделение сгущений этих точек.
- Существует два основных типа кластерного анализа: иерархический и анализ k средних.
- Иерархический кластерный анализ применяется только при малых объемах выборки.
- Анализ k средних используется для работы с большими данными.

> [!info] Определение: Кластерный анализ
> Группа методов, используемых для классификации объектов или событий в относительно гомогенные группы.

## Алгоритм и этапы иерархической кластеризации

- В иерархическом кластерном анализе каждое наблюдение изначально образует свой отдельный кластер.
- На первом этапе анализа два наиболее соседних кластера объединяются в один.
- Процесс слияния продолжается до тех пор, пока не останется два кластера (или один, в зависимости от реализации, но в лекции указано два).
- Расстояние между кластерами определяется как среднее значение всех расстояний между всеми возможными парами точек из обоих кластеров.
- Этапы кластерного анализа включают: формулировку проблемы, выбор способа измерения расстояния, выбор метода кластеризации, принятие решения о количестве кластеров, интерпретацию и профилирование, оценку достоверности.
- Самой распространенной мерой для определения расстояния между точками является евклидова мера.

> [!info] Определение: Иерархический кластерный анализ
> Метод кластеризации, при котором каждое наблюдение начинает с отдельного кластера, а затем кластеры последовательно объединяются на основе расстояния между ними.

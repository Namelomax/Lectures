# Лекция 1. Оценка качества моделей Random Forest

> [!abstract] Кратко
> Лекция посвящена методологии оценки качества деревьев в ансамбле Random Forest. Рассматривается процесс случайного выбора признаков и построения отдельных деревьев. Для оценки точности используется метод квадратного отклонения. Приводится практический пример расчета среднего значения и анализа данных. Отдельно упоминается влияние выбросов на качество моделей.

> [!tip] Главное
> - В Random Forest качество каждого дерева оценивается с помощью метода квадратного отклонения.
> - Деревья в ансамбле строятся на основе случайного выбора значений признаков.
> - Для иллюстрации расчетов используется таблица данных с переменными y, x и z.
> - Среднее значение переменной y в примере составляет 6,8.
> - Понятие выбросов является важным аспектом при оценке качества данных и моделей.

## Оценка качества деревьев в Random Forest

- В методе Random Forest случайным образом выбираются значения признаков для построения отдельных деревьев.
- Полученные деревья разграничиваются по выбранным случайным значениям.
- Качество каждого дерева оценивается с помощью метода квадратного отклонения.
- Для иллюстрации процесса приведена таблица данных с переменными y, x и z.
- В примере значения переменной y составляют 1, 1, 2, 10 и 20.
- Среднее значение (Ср) для переменной y в данном примере равно 6,8.

> [!info] Определение: Random Forest
> Метод, при котором случайным образом выбираются значения признаков для построения множества деревьев, качество которых оценивается по методу квадратного отклонения.

> [!example] Примеры
> - Таблица данных с переменными y, x, z и средним значением y равным 6,8.
